# Code of conduct

Merlo is a technical research project. Participation requires clear, evidence-based discussion and professional treatment of other contributors.

## Expected conduct

- Critique code, claims, and methods rather than people.
- State uncertainty and distinguish measured results from hypotheses.
- Provide reproducible examples for technical disagreements when practical.
- Respect privacy, security embargoes, and repository licenses.
- Keep issue and review threads relevant to the change under discussion.

## Unacceptable conduct

Harassment, threats, discriminatory language, sexualized attention, doxxing, deliberate disruption, and publication of private security reports are not accepted in project spaces.

## Enforcement

Report conduct issues through the maintainers' private GitHub contact or, when the report is security-sensitive, through the repository security-reporting path. Maintainers may edit or remove content, close threads, restrict participation, or ban accounts. Reports are reviewed with attention to context, impact, and conflicts of interest.

This policy applies to repository discussions, pull requests, issues, and project-managed community spaces.
