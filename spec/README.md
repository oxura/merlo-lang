# Merlo alpha specification

The files in this directory define the normative behavior of `0.1.0-alpha.2`. User guides in `docs/` may explain the same behavior more broadly; when wording differs, the specification is authoritative for the alpha.

- [Language core](language.md)
- [Ownership and borrowing](ownership.md)
- [Effects and capabilities](effects.md)
- [Packages and lockfiles](packages.md)
- [FFI boundary](ffi.md)
- [SemanticWorld](semantic-world.md)
- [AlphaProtocol](alpha-protocol.md)

The specification covers only implemented behavior. Proposed syntax or runtime features belong in `rfcs/` and do not become normative until implemented, tested, and incorporated here.
